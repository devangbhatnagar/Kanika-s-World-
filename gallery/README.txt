Put your photos and videos in this folder.

Supported photos: .jpg, .jpeg, .png, .webp, .gif
Supported videos and reels: .mp4, .webm, .mov

Keep files directly inside this folder (no subfolders). The gallery uses each
filename as its caption. For a static hosting update, run npm run build again
and redeploy the contents of dist/. When using npm start, refresh the gallery
after adding files.
